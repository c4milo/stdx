# stdx 0.4.0

This is a MINOR release ([decision 65](https://github.com/c4milo/stdx/blob/v0.4.0/docs/decisions.md)).
It adds `stdx.crypto`, chapulin's cryptography through one value that a program makes once. The
package now exports the module `stdx` alone, `json` and `base64` move under `stdx.encoding`, and
`platform.CpuFeatures` is the one CPU type. No encoder writes bytes other than the ones 0.3.0
writes.

```bash
zig fetch --save git+https://github.com/c4milo/stdx#v0.4.0
```

## Added

- `stdx.crypto`: [chapulin](https://github.com/c4milo/chapulin)'s TLS 1.3 over TCP and under
  QUIC, JSON Web Signatures, DNSSEC, SCRAM's calls, and the hashes, HMAC and HKDF of chapulin's key
  schedule. stdx writes no cryptography of its own (decision 87). A dependent asks for it with
  `.crypto = true`. A dependent that does not fetches no chapulin and compiles no C.
  - `stdx.crypto.init(features, random)` returns a `Context` once, when the program starts. It
    holds the program's `CpuFeatures` and a cryptographically secure random source.
    `src/crypto/README.md` shows a source over `io.randomSecure`.
  - A program calls through that value: `crypto.hash.sha256(&digest, bytes)`, with SHA-384,
    SHA-512, SHA-3, SHAKE, HMAC and HKDF beside it, and `crypto.jws.sign(&out, key, input)`.
    `init` computes chapulin's description of the CPU once: a SHA-256 of "abc" spends 22
    instructions outside chapulin's C.
  - `stdx.crypto.tls` and `stdx.crypto.quic` hold the sessions and their options. Each
    session's `init` takes the `Context`, so chapulin's description of the CPU and its random
    source come from the value alone.
  - A session runs AES-GCM only where stdx states that the AES and carry-less multiply
    instructions run in a time independent of their data: on x86-64 always, and on arm64 while
    the thread's PSTATE.DIT is set. Elsewhere it runs ChaCha20-Poly1305.
- `stdx.platform.set_data_independent_timing` and `stdx.platform.data_independent_timing`: set
  and read the calling thread's PSTATE.DIT on arm64 (decision 40 as amended). On x86-64 only the
  kernel holds DOITM.
- `CpuFeatures` holds what `platform.Cpu` held, with `bool` in place of `Answer`: `sse4_1`, `aes`,
  `sha256`, `sha512`, `sha3`, `sve2`, `dit`, `vaes` and `midr`.
- `CpuFeatures.detect()` sets `dit` on an Arm Neoverse N2 whose hypervisor hides FEAT_DIT from
  `AT_HWCAP`, as GitHub's arm64 runners do. It reads the core from MIDR_EL1, and
  `zig build platform-check` sets, reads back and clears PSTATE.DIT on such a core (953c24c).
- `stdx.regex` runs faster on rebar's benchmarks: claims R11 to R15 search from a text's end, a
  literal's places, a window before a literal, and a trie by Aho and Corasick. The Lean model
  of the matcher proves each claim's search, and a seeded check holds the searcher to it. No
  public name of `regex` changed.

## Changed

- The package exports one module, `stdx`. A dependent imports `dependency.module("stdx")`, and
  the build refuses a second export (decision 6 as amended, b643d58). The aliases that 0.3.0 kept
  are gone.
- `json` and `base64` sit under `stdx.encoding`, and the module `checksum` is `hash`
  (https://github.com/c4milo/stdx/issues/41, f233091).
- `platform.CpuFeatures` grows to 30 bytes, so a state that keeps one, such as the DEFLATE
  decoder's, grows too. The JSON reader keeps no copy, so a small decode takes as many
  instructions as before (a11db0b).

## Removed

- `platform.probe`, `platform.Cpu` and `platform.Answer`. A program calls
  `platform.CpuFeatures.detect()` once, and `platform` makes no syscall (923d812).

## Fixed

- A program can size a buffer by the Zstandard and brotli encoders' `encoded_len_max` at compile
  time (1b32873, 3d39f08).
- A searcher that judged claim R14 after its searches filled the forward DFA's cache no longer
  halts (6fd0408).

| --- | --- |
| `dependency.module("deflate")` | `stdx.compress.deflate` |
| `dependency.module("zlib")` | `stdx.compress.zlib` |
| `dependency.module("gzip")` | `stdx.compress.gzip` |
| `dependency.module("zstd")` | `stdx.compress.zstd` |
| `dependency.module("brotli")` | `stdx.compress.brotli` |
| `dependency.module("checksum")` | `stdx.hash` |
| `dependency.module("json")`, `stdx.json` | `stdx.encoding.json` |
| `dependency.module("base64")`, `stdx.base64` | `stdx.encoding.base64` |
| `dependency.module("platform")` | `stdx.platform` |
| `platform.probe()` | `platform.CpuFeatures.detect()` |
| `platform.Cpu` | `platform.CpuFeatures` |
| `platform.Answer` | `bool` |
